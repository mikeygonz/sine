# Agents

- Every task gets a Linear issue in Monarch Computer Labs before work starts.
- Document the work in that issue as you go: proposals, decisions and the reasons for them, techniques, and art directions with their images or PDFs attached.
- End each session with a handoff comment on the issue: what changed, what is left, and anything the next agent needs to pick it up without asking.
- Keep it a static page with no build step and no runtime dependencies. No external requests from the page: no CDNs, remote fonts, or analytics.
- Copy is short and plain. No em dashes.
